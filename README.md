# 🎬 Downloader

Aplicación de escritorio desarrollada con **JavaFX** que permite descargar videos desde plataformas como **YouTube**, utilizando `yt-dlp` y `ffmpeg` para convertir el formato final del video.

---

## Funcionalidades

- ✅ Descarga de videos mediante `yt-dlp`
- 🎧 Conversión automática a formatos como `.mp3` o `.mp4` usando `ffmpeg`
- 📁 Interfaz gráfica amigable construida con JavaFX (FXML)
- 🔊 Barra de progreso para indicar el estado de la descarga

---

## Tecnologías utilizadas

- 💻 Java 21
- 🖼 JavaFX
- 📦 Maven
- 🔧 yt-dlp
- 🎞 ffmpeg
